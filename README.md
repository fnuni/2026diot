# Edge coordination under infrastructure outages - software and synthetic data

Companion repository for:

> F. Nucci, G. Papadia. *What Makes Edge Coordination Resilient? A Negative Result on Vehicle Autonomy in Home-Healthcare IoT.* Submitted to *Discover Internet of Things*, Collection “Agentic AI-Empowered Edge Intelligence and Next-Generation IoT Systems”.

This is the publication package at repository root. It contains one deterministic simulator, one configuration, one two-phase synthetic study, tests, result tables, and a representative raw-log replay. No cover letter, submission e-mail, manuscript source, personal data, or clinical record belongs in the public repository.

## Main findings represented by the artefact

| Study phase | Seeds | Runs | Endpoint | Finding |
|---|---:|---:|---|---|
| Screening, S1-S5 | 8001-8040 | 10,192 | PWH: priority-weighted on-time request handling | Under the declared fog-ingress topology, Hybrid - Central is +4.68 pp [3.80, 5.57] during the 120-min cloud outage, but -0.12 pp [-0.53, 0.25] under severe vehicle coverage gaps. S2 includes N4 at every load/fleet cell. |
| Confirmatory, C1-C3 | 9001-9040 | 2,080 | PWS: priority-weighted completed on-time service | Fog placement is +5.76 pp [4.89, 6.63]; vehicle fallback is -0.08 pp [-0.45, 0.28]. Hybrid - Central@fog is -0.39 pp in the benign bundle but -1.20 pp in thermal stress, so equivalence is not robust across bundles. |

The simple `GREEDY_FOG` baseline is included in C1 and C2. It remains available during the cloud outage but is substantially weaker than fog-hosted ALNS for short and medium outages. At 120 min in the stress bundle it is 1.83 pp below cloud control; only at 180 min does availability dominate policy quality (+12.02 pp). This separates the value of *having any fog dispatcher* from the value of its policy.

All records are synthetic. Results quantify one declared failure and ingress topology; they do not establish clinical effectiveness, outage frequency, hardware feasibility, or a general benefit of agentic autonomy.

## Quick start

Python 3.10 or later is required. The simulator uses the standard library; analysis and tests require the packages in `requirements.txt`.

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt

python -m aedge.release_integrity
python -m pytest -q tests
python scripts/check_analyses.py
python scripts/thermal_sensitivity.py --out reproduced_thermal.json
```

`check_analyses.py` recomputes both analysis layers from the distributed run tables in a temporary directory and compares every JSON field with the archived outputs.

## Re-running simulations

Write reruns to a new directory. Trajectory hashes exclude host timing fields; compare `trajectory_sha256`, not wall-clock values.

```sh
python -m aedge.experiment --stage S1 --output reproduced_screening --workers 4
python -m confirmatory.campaign --out reproduced_confirmatory --workers 4
python -m confirmatory.analyse --out reproduced_confirmatory
```

The included `examples/replay/` folder demonstrates the complete event-log format without requiring a multi-gigabyte archive. Full raw logs can be regenerated by the commands above. ## Guarantees and limits

- The model-based vehicle agents are classical deliberative agents, not learned or generative agents.
- N4 assumes that requests enter at a district call centre hosted with the fog coordinator, vehicles retain N1-quality access to that endpoint, and only the fog-cloud backhaul or cloud provider path is unavailable. The paper restricts its placement claim to this topology.
- The ownership protocol is a versioned-ownership/fencing-token scheme with one authoritative coordinator. It provides safety under its assumptions, not consensus, coordinator failover, crash recovery, security, or liveness for work held by a disconnected vehicle.
- The thermal result is a conditional analytical bound, not regulatory certification. It depends on declared conductance ratios, heat capacity, ambient bounds, opening separation and exact virtual sensing. `calibrate_class` raises an error when the cold-life target is not bracketed.
- The warm-season simulations do not exercise freeze risk. A physical deployment needs measured carrier parameters, bounded logger error and cold-season tests.
